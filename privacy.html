Privacy Policy — Olaguez Fashion Discovery

Last updated: 2026-09-14

What this project is

Olaguez Fashion Discovery is a pre-launch, personal software project built by one individual developer, Alexander Olaguez. It is not a company. It has no public users, no sign-up flow, and no live release. This policy describes what the project does and does not do with data today, and is written against the actual current design rather than a future plan.

Current status: no public users

There is no public product to sign up for. The only person who uses this project today is its developer, testing it against his own accounts, in order to evaluate whether the approach works before building it for anyone else. If that changes, this policy will be updated before it does, and any Pinterest integration expanded beyond this developer's own account would first go back through Pinterest's own review process for that change.

What data this project collects

By default: none. There is no account creation, no marketing site with tracking, and no analytics on any page hosting this policy.

If a Pinterest account is connected (currently, only the developer's own account, for testing): with that account's authorization, the project reads that account's own boards and pins through Pinterest's API. It reads only the content belonging to the Pinterest account that connected — never another Pinterest user's boards or pins. Those images are processed in memory by a self-hosted, off-the-shelf image-recognition model with fixed, unchanging weights, producing a numerical description of visual style. That description is used to rank items from third-party resale marketplaces (for example, listings on eBay) so the connected account can see items similar to what it has pinned. Nothing about this process trains, fine-tunes, or otherwise changes the image-recognition model — it is identical before and after use.

What this project does not do

  • It does not display, republish, share, or redistribute any Pinterest content, to any other user or to any third party, anywhere.
  • It does not combine one person's Pinterest data with anyone else's data.
  • It does not store Pinterest images, pin text, board structure, or any other Pinterest content beyond the single request that processes it. See “Retention and deletion” below.
  • It does not sell, rent, or share any data with third parties for their own purposes, including for advertising.
  • It does not run advertising, and does not use any data from Pinterest to target advertising anywhere, on or off Pinterest.
  • It does not process payments, hold inventory, or handle any purchase. Clicking through to a marketplace listing takes you to that marketplace's own site, which has its own privacy policy governing what happens there — this project does not see or receive anything about what happens after that click.

Retention and deletion

Nothing derived from a connected Pinterest account is stored. Images, the numerical style description computed from them, and any other intermediate result exist only for the duration of the single request that produces them, and are discarded immediately afterward. There is currently no database, file store, log pipeline, or backup that this data passes through or persists in.

If that ever changes — for example, if Pinterest grants permission for this project to store a derived style profile so a connected account does not have to reconnect every time — this policy will be updated before that storage begins, and it will describe: what is stored, for how long, and how to have it deleted. Any authorization to connect a Pinterest (or other) account can be revoked at any time by disconnecting it, which immediately invalidates the access token this project was using; no further requests can be made on that account's behalf after that.

Children's privacy

This project does not knowingly collect data from children and is not directed at children. Because there is no public sign-up, this has not yet been tested in practice; it will be revisited if the project moves toward having real, public users.

Changes to this policy

This is a living document for a project that does not yet have real users. It will be updated as the project's actual behavior changes, and the date at the top will reflect the most recent update. Material changes that would affect a connected Pinterest account will not be made silently.
