Olaguez Fashion Discovery

A personal, pre-launch software project by Alexander Olaguez.

What it is

A fashion discovery tool: it aims to learn a person's style preferences and use them to surface matching clothing from third-party resale marketplaces, linking out to the marketplace that owns each listing. It does not sell anything, hold inventory, or process payments — it links to marketplaces that do.

Status

Pre-launch. There are no public users. The developer is currently the only person using it, to test whether the approach works before building it for anyone else.
